# 🐾 Pet Adoption System

A full-stack web application designed to simplify the pet adoption process by connecting adopters with shelters through a structured, role-based platform. The system streamlines pet listings, adoption requests, medical record management, and feedback while ensuring efficient database management and workflow automation.

---

# Project Overview

The Pet Adoption System was developed as an academic full-stack web development project to address common issues in traditional pet adoption processes such as:

- Manual record keeping
- Inefficient adoption tracking
- Lack of centralized pet information
- Difficult communication between adopters and administrators

The application digitizes the complete adoption workflow using a relational database and role-based access control.

---

# Problem Statement

Many local shelters maintain adoption records manually, making it difficult to:

- Track available pets
- Maintain adopter information
- Store medical records
- Monitor adoption history
- Manage approvals efficiently

This project provides a centralized solution that automates these processes.

# Database Design

The application uses a normalized relational database to minimize redundancy and maintain data integrity.

Main entities include:

- Users
- Pets
- Adoption Requests
- Medical Records
- Feedback
- Administrators

Relationships are maintained using Primary Keys and Foreign Keys.

Database concepts used:

- Normalization
- Referential Integrity
- Primary Keys
- Foreign Keys
- CRUD Operations
- SQL Joins
